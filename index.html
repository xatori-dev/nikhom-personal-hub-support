Nikhom’s Personal Hub — privacy policy

Effective date: October 15, 2026.

Nikhom’s Personal Hub provides a calendar and personal tools, starting with Nikhom Financials. It does not require an account. The calendar stores event names, dates, times, and chosen symbols on your device. Financials stores the balances, bill names, categories, amounts, due dates, expenses, and pay-period settings you enter on your device.

The app does not transmit this information to the developer or a cloud database. It does not connect to your bank accounts, include advertising, or collect analytics.

The optional Nikhom Assistant provides built-in quick help, local AI and user-configured cloud AI. Quick help does not send records to an AI service. Local AI sends requests and permitted tool results only to a local Ollama engine on the same device; its remote/cloud models remain blocked. Your model runtime is a separate program; review its settings and access.

If you explicitly enable OpenAI, OpenRouter or another compatible HTTPS provider with your own API key, your requests, relevant recent conversation, up to three relevant saved memory entries, enabled Calendar/Financials tool results and selected-period dates are sent to the displayed API destination. OpenRouter routes requests to the selected model's provider. These services receive your connection information and apply their own pricing, access and retention policies; the developer does not operate an AI proxy. Testing a connection runs one small synthetic tool-support test that may consume credits; it contains no app records. An approved saved connection can resume after reopening, with the same provider, model and data access. Changing connection details or data access requires fresh approval. OpenAI requests specify `store: false`; that setting is not a guarantee of zero provider retention.

Save stores native API keys in secure device storage or browser keys in an encrypted browser vault. The browser encryption key is non-exportable and stays in that browser's storage. Saved keys and models are separate on each device. Keys never enter app records, backups, exported reports or model context. The app ships no shared key. You can replace or remove a saved key in Assistant settings; removing it does not revoke the key at its provider. Conversations are not retained. Changing assistant access clears the conversation and unsaved plan.

Names and bounded saved memory remain on the device. You can manage them in Names & memory settings or with remember/forget commands. Optional learning captures only clear, short personal preference statements. Memory recall uses the current question and enabled data scopes; it can be disabled. These preferences are separate from financial backups. Clearing app/browser storage removes them.

With immediate commands enabled, clear, locally understood human requests can add, edit or remove supported records without another confirmation. Ambiguous targets ask for clarification. Model-generated changes remain drafts that require an explicit Save. Up to 50 redacted action receipts are kept with local records and encrypted backups; they contain no prompts, event names, keys or financial amounts. The last event removal also stores the bounded removed events locally and in encrypted backups so Undo can restore them after reopening.

The Hub fetches a public daily Leo horoscope from AstroWay over HTTPS. Requests contain only the zodiac sign, reading date, and language. The user’s birthday, calendar events, and financial records are not sent. As with any internet request, the provider receives the connection's IP address. The app saves the latest public reading locally for offline use. These readings are AI-generated entertainment and self-reflection content. A saved older reading displays its original date when a new reading cannot load. No horoscope account or API key is required.

If you choose to export an Excel report or create a backup, Android opens its system file-saving dialog. Restoring a backup opens its system file picker. The optional browser preview uses download or sharing options. The destination you choose may have its own privacy policy. Excel reports are ordinary, unencrypted files. Restorable backups are encrypted with the password you choose; the developer cannot recover that password.

Data remains on the device until you edit or delete it or remove the app's storage. The app does not automatically synchronize data across devices. Before uninstalling or replacing a phone, create a backup if you want to retain your records. You control copies you save outside the app.

The optional web preview stores data in the browser and is separate from the Android app. Clearing that browser's site data removes preview records.
